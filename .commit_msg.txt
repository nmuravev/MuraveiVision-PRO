fix(auth): DB-backed session tokens survive restart (B6.1)

Replace in-memory _active_tokens with hybrid store:
- SQLite session_tokens table for persistence
- In-memory cache synced from DB on startup (last 24h)
- _sync_db_to_memory() on lifespan start
- All token ops (create/invalidate/cleanup) touch both memory + DB

Root cause: Auth 401 after backend restart — in-memory tokens lost.
Migration: Users re-login once after restart (old tokens invalidated).
