# Руководство аналитика

Аналитик работает с результатами детекции: проверяет, исправляет, собирает отчёты и экспортирует датасеты. Роль не требует PIN инженера — достаточно входа оператора/аналитика. Фокус — качество и достоверность данных.

## Вход

1. `Запустить.bat` (или `http://127.0.0.1:8000`).
2. PIN аналитика/оператора (по умолчанию `1234567`; сменить после первого развёртывания).
3. Открыть вкладку **Монтаж**.

## Просмотр и проверка детекций

1. MediaPool → перетащить видео во Viewer.
2. Inspector показывает список детекций **только текущего ролика** (scoped-фильтр по `source_video`). Сверху — `N/N` текущего ролика.
3. Сверить оверлеи YOLO с кадром: бейдж модели / ms / device во Viewer. Если `mode != ready` — см. [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md) («Если ничего не детектит»).
4. Переключение вкладок сохраняет scoped-N (soft-delete переживает переключения).

## Исправление и правка

- **Класс:** в Inspector сменить класс детекции; в режиме рисования во Viewer — выбрать класс в `<select>` перед рамкой.
- **Заметки:** `user_notes` (дебаунс), сохраняются в БД.
- **Флаг/soft-delete:** пометить ложную детекцию `is_deleted` (не удаляется физически — остаётся для аудита).
- **Bulk «Очистить»:** мягко удалить все детекции текущего ролика.
- **Ollama autolabel (опц.):** в Inspector «Предложить класс через Ollama» → предложение с confidence/reason → «Принять» патчит детекцию, «Отклонить» очищает предложение.

## Active Learning

Вкладка **Обучение** → очередь Active Learning:
1. Low-confidence детекции собраны автоматически (`POST /api/active-learning/collect`).
2. Подтвердить полезные (`accepted`) — остаются в датасете.
3. Отметить ложные (`rejected`) — исключаются soft-delete.
4. Решение фиксирует `POST /api/active-learning/{id}/decision`.

## Кропы и галерея

- «Зафиксировать кадр» → кроп в BattleGallery.
- Галерея — сетка кропов по `moments`; фильтр по классу/ролику.
- Кропы — материал для дообучения и отчётов.

## Отчёты и экспорт

- **HTML-отчёт:** TopBar → автономный HTML-файл (открывается без сервера).
- **PDF/geo-карта:** вкладка отчётов, GPS-точки по SRT/CSV телеметрии (если есть).
- **Экспорт датасета YOLO:** для внешнего дообучения (формат YOLO).
- **Diagnostic ZIP:** если нужна помощь инженера — собрать Support-архив (роль инженера, см. [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md)).

## Compare Sync (сверка двух ракурсов)

1. Layout preset «2 Viewer».
2. Перетащить второй ролик во Viewer-2.
3. «Sync» — синхронизация воспроизведения, drift-correction 500мс.
4. Сверить детекции по таймстампу между ракурсами.

## Достоверность (важно)

- Response Validator отбрасывает аномальные детекции (bbox/conf/area/class_id) — см. `logs/validator_rejections.jsonl`. Если аналитик видит систематические отбросы — сообщить инженеру.
- Правила/alerts (вкладка AI-анализ) — cooldown 3с, локальный сигнал при срабатывании, авто-фиксация в галерее.
- SAHI (если включён инженером) — для мелких объектов на 4K-кадрах; не меняет формат детекций.
