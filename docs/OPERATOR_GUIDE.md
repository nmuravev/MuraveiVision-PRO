# Руководство оператора

Полевая работа: съёмка/стрим, фиксация детекций, разметка, отправка целей. Диагностика/настройка — [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md), проверка/отчёты — [ANALYST_GUIDE.md](ANALYST_GUIDE.md).

## Старт

1. Portable: `Запустить.bat`.
2. Браузер `http://127.0.0.1:8000`.
3. PIN оператора (по умолчанию `1234567`; сменить после первого развёртывания).

## Типовой сценарий разметки

1. MediaPool → перетащить видео во Viewer.
2. **YOLO вкл** — покадровые рамки (выкл — без WS). В Архиве: **«Сканировать»** по ролику или I–O. Тумблер **Сегментация** → Загрузить → «Сегментировать кадр» (пауза). Live остаётся детекцией.
3. Выбрать класс ручной рамки во Viewer либо поправить класс в Inspector. Для кропа — запросить предложение Ollama и принять/отклонить.
4. «Зафиксировать кадр» → кропы в BattleGallery.
5. In/Out (`I`/`O`) задают сегмент для «Сканировать» / «Построить 3D».

## 4×Live и лента событий

Вкладка **4×Live** (или Раскладка → «4×Live»): четыре вьюера 2×2 и панель «События» снизу. Вьюеры открываются в режиме Live — URL стрима задаётся отдельно в каждом, Архив/Live переключаются независимо.

Лента опрашивает сервер каждые 3 секунды (окно 5 минут). Фильтры: все / только локальные / только сеть / конкретный класс. Новые строки появляются сверху (можно выключить авто-скролл).

- Локальная детекция — клик перематывает тот Viewer, где открыт тот же ролик, к времени кадра.
- Сетевая цель — клик показывает базу-источник, GPS и заметки. Удалённое видео отсюда не открывается.

Меню Раскладка → «4 вьюера» — другой пресет (пул + инспектор + таймлайн разметки), его 4×Live не заменяет.

## Live

В Viewer переключить Архив|Live, указать RTSP/UDP/HTTP. REC пишет в `archive/recordings/`. Если стрим «молчит» — система пометит его неактивным по open-timeout.

## Скорость воспроизведения

0.25×–4× выбирается на Timeline и применяется к реальному `<video>`.

## Гео (SRT / CSV)

Положите рядом с видео в `archive/` файл с тем же именем: `ролик.SRT` или `ролик.CSV` (DJI-подписи). При фиксации кадра и пакетном скане координаты пишутся на детекцию. Старые строки без GPS обновляются при открытии ролика или из панели Гео 3D. Без sidecar GPS нет (OCR OSD не используется).

## Обучение (вкладка «Обучение»)

1. Зафиксируйте ≥3 кропа.
2. **Быстрое улучшение** — detect YOLO26, по умолчанию imgsz 640 / batch 4 (безопасно для ноутбука 8 ГБ). Ползунки выше — риск OOM (жёлтый/красный).
3. Если обучение оборвалось — **Продолжить обучение** (нужен `last.pt` в списке точек восстановления).
4. Seg/YOLOE как база запрещены.

## 3D (показать в 3D)

В Inspector «Показать в 3D» открывает Flight3D, строит луч из COLMAP intrinsics, использует splat pick → sparse fallback. Если пересечения нет — `Пересечение не найдено`.

## Сеть баз

SYSTEM → Сеть: обмен целями и чат с другими базами (режим server/client настраивает инженер). Входящие цели появляются после синка (~30 с), не мгновенным локальным зеркалом. Цели несут `source_video` (ролик-источник).

## Если «ничего не детектит»

1. Проверить бейдж модели во Viewer: `mode ready`?
2. conf не завышен?
3. Ollama offline не блокирует YOLO — только AI-вкладку.
4. Если не помогло — звать инженера (см. [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md)).
