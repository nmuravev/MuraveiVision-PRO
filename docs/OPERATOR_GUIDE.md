# Руководство оператора

Полевая работа: съёмка/стрим, фиксация детекций, разметка, отправка целей. Диагностика/настройка — [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md), проверка/отчёты — [ANALYST_GUIDE.md](ANALYST_GUIDE.md).

## Старт

1. Portable: `Запустить.bat`.
2. Браузер `http://127.0.0.1:8000`.
3. PIN оператора (по умолчанию `1234567`; сменить после первого развёртывания).

## Вкладки TopBar

| Вкладка | Задача |
|---------|--------|
| Медиа | обзор архива, просмотр |
| Монтаж | разметка, Inspector, кропы, In/Out |
| AI-анализ | Ollama по кадру/кропу, правила/тревоги |
| Обучение | быстрое дообучение на кропах |
| Система | железо, сеть, импорт модели (инженер) |

## Типовой сценарий разметки

1. MediaPool → перетащить видео во Viewer.
2. Дождаться оверлеев YOLO (бейдж модели / ms).
3. Выбрать класс ручной рамки во Viewer либо поправить класс в Inspector. Для кропа — запросить предложение Ollama и принять/отклонить.
4. «Зафиксировать кадр» → кропы в BattleGallery.
5. In/Out (`I`/`O`) → Queue → экспорт ZIP фрагментов.

## Live

В Viewer переключить Архив|Live, указать RTSP/UDP/HTTP. REC пишет в `archive/recordings/`. Если стрим «молчит» — система пометит его неактивным по open-timeout.

## Скорость воспроизведения

0.25×–4× выбирается на Timeline и применяется к реальному `<video>`.

## 3D (показать в 3D)

В Inspector «Показать в 3D» открывает Flight3D, строит луч из COLMAP intrinsics, использует splat pick → sparse fallback. Если пересечения нет — `Пересечение не найдено`.

## Сеть баз

SYSTEM → Сеть: обмен целями и чат с другими базами (режим server/client настраивает инженер). Входящие цели появляются после синка (~30 с), не мгновенным локальным зеркалом. Цели несут `source_video` (ролик-источник).

## Если «ничего не детектит»

1. Проверить бейдж модели во Viewer: `mode ready`?
2. conf не завышен?
3. Ollama offline не блокирует YOLO — только AI-вкладку.
4. Если не помогло — звать инженера (см. [ENGINEER_GUIDE.md](ENGINEER_GUIDE.md)).
