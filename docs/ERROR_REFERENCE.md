# Справочник ошибок MuraveiVision PRO

Полевой справочник: HTTP-код → смысл → причины → что сделать.
Backend отдаёт тот же текст в поле `error` ответа (см. `backend/services/error_catalog.py`), UI показывает модалку «Ошибка N: …».

Ответ API остаётся совместимым с FastAPI: поле **`detail`** сохраняется; рядом добавляется **`error`**.

```json
{
  "detail": "File not found",
  "error": {
    "code": 404,
    "name": "NOT_FOUND",
    "title": "Ресурс не найден",
    "message": "File not found",
    "causes": ["…"],
    "solutions": ["…"],
    "docs_url": "…#404"
  }
}
```

---

## 400 Bad Request

**Заголовок:** Неверный запрос

**Причины:**
- Отсутствует обязательный параметр
- Неверный формат данных
- Превышен лимит размера файла

**Решения:**
- Проверьте параметры запроса в документации API
- Убедитесь, что файл соответствует формату (mp4, jpg, pt)
- Размер файла не должен превышать допустимый лимит

**Примеры:** `POST /api/detections` без body; `GET /api/media/frame` без `path`

---

## 401 Unauthorized

**Заголовок:** Требуется авторизация

**Причины:**
- PIN не введён или неверный
- Сессия истекла или токен недействителен
- Запрос без заголовка Authorization

**Решения:**
- Введите PIN оператора (`1234567`) или инженера (`0000000`)
- Перезайдите в систему через TopBar
- Проверьте Bearer-токен в запросе

**Примеры:** `POST /api/seg/load` без токена

---

## 403 Forbidden

**Заголовок:** Доступ запрещён

**Причины:**
- Роль пользователя недостаточна для операции
- Операция доступна только инженеру/мастеру
- Попытка изменить защищённые настройки

**Решения:**
- Войдите как инженер (PIN `0000000`)
- Обратитесь к инженеру смены
- Проверьте роль в TopBar

---

## 404 Not Found

**Заголовок:** Ресурс не найден

**Причины:**
- Видео удалено или перемещено из `archive/`
- Неверный путь к файлу
- Модель не найдена на диске / не загружена в VRAM
- Детекция или объект не существует в БД

**Решения:**
- Проверьте файл в Медиапуле (Обновить)
- Проверьте путь без лишних спецсимволов
- Загрузите seg-модель: Viewer → Сегментация → Загрузить
- Проверьте ID детекции в Inspector

**Примеры:** `GET /api/media/frame?path=missing.mp4`; `GET /api/detections/{id}`

Нет sidecar `.SRT`/`.CSV` у ролика — это не 404: `POST /api/geo/import` отвечает 200 с `sidecar_missing`.

---

## 409 Conflict

**Заголовок:** Конфликт состояния

**Причины:**
- Ресурс уже занят другой операцией
- Повторный запуск при активном процессе
- Конфликт версий данных

**Решения:**
- Дождитесь завершения текущей операции
- Остановите конфликтный процесс и повторите
- Обновите UI (F5)

---

## 422 Validation Error

**Заголовок:** Ошибка валидации

**Причины:**
- Поле отсутствует или имеет неверный тип
- Значение вне допустимого диапазона
- Некорректный JSON в теле запроса

**Решения:**
- Сверьте тело со схемой в [API.md](API.md)
- Проверьте типы полей
- Исправьте обязательные поля и повторите

---

## 429 Too Many Requests

**Заголовок:** Слишком много запросов

**Причины:**
- Превышен лимит частоты запросов
- Слишком частые вызовы inference/export

**Решения:**
- Подождите несколько секунд
- Снизьте частоту опроса API
- Не запускайте параллельно тяжёлые операции

---

## 500 Internal Server Error

**Заголовок:** Внутренняя ошибка сервера

**Причины:**
- Непредвиденная ошибка в коде backend
- Сбой зависимости (OpenCV, YOLO, БД)
- Повреждённый файл или кэш

**Решения:**
- Проверьте логи / DebugPanel
- Перезапустите сервер (`Запустить.bat`)
- Сообщите инженеру текст ошибки и время

---

## 503 Service Unavailable

**Заголовок:** Сервис временно недоступен / веса DA3 не найдены

**Причины:**
- Модель не загружена в VRAM
- Backend или GPU перегружены
- Внешний сервис (Ollama) недоступен
- Превышен лимит одновременных задач
- `DA3_WEIGHTS_NOT_FOUND`: файлы весов `da3_base.safetensors` или `da3_large.safetensors` отсутствуют в `sidecars/da3/` (Mini без sidecar или FullKit без seed)
- `DA3_RUNTIME_UNAVAILABLE`: пакет `depth_anything_3` не импортируется / модель не загрузилась; плоский depth-fallback отключён (анти-мусорное облако-стена)

**Решения:**
- Загрузите модель (`POST /api/seg/load` или кнопка «Загрузить»)
- Подождите ~30 секунд и повторите
- Проверьте GPU / DA3: `GET /api/system/hardware` (`da3.base_present` / `da3.large_present`)
- Для DA3: скопируйте веса в `sidecars/da3/` из FullKit или `scripts\stage_da3_sidecar.ps1`; либо переключитесь на AliceVision Dense
- Для `DA3_RUNTIME_UNAVAILABLE`: установите `depth-anything-3` в `muravei_env` (+ wheel в `portable/cache/wheels` для air-gap bake)
- Закройте другие GPU-приложения

**Примеры:** `POST /api/recon/train/start` с `preset=da3_dense_base` при пустом `sidecars/da3/` или без `depth_anything_3`; `POST /api/seg/infer` при `loaded=false`
