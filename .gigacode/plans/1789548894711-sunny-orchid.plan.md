# N5: Opt-in LAN Beacon (no secrets in UDP)

## Background

N1–N4 are merged to `main` at `61b3d2c`. N5 adds a lightweight LAN discovery mechanism: each node broadcasts `base_id`, `base_name`, `port` via UDP broadcast — **no PIN/secrets in UDP**. Discovery does **not** authorize; JWT on subsequent REST/WS remains the gate. Opt-in only, never on boot.

**Plan source:** `.cursor/plans/full-build_unlock_n-v-b-p_4b196fe6.plan.md` → N5 section.

---

## Requirements (locked)

1. **Opt-in toggle** — `lan_beacon_enabled` in `network_config` table, default `false`.
2. **Never on boot** — beacon task starts only if config says `enabled`; no background process on startup.
3. **UDP payload** — JSON: `{ "base_id", "base_name", "port", "ts" }`. No PIN, no JWT, no secrets.
4. **Broadcast** — `255.255.255.255` (or subnet-directed broadcast), configurable port (default `8001`), interval ~2 s.
5. **Discovery listener** — receive UDP, parse JSON, call `net.heartbeat()` to register peer in `network_bases` (same table as hub heartbeat).
6. **Config** — `lan_beacon_port` (default 801), `lan_beacon_enabled` (bool).
7. **UI** — toggle in NetworkPanel (SYSTEM → Network) + status line "Beacon: on/off".
8. **Security** — beacon never grants access; only REST/WS with JWT authorize.

## Implementation Map

### 1. Backend: `services/network_beacon.py` (new)

```python
"""Opt-in LAN UDP beacon: broadcast + discovery."""
import asyncio
import json
import socket
import time
from typing import Any

BEACON_PORT = 8001  # configurable
BEACON_INTERVAL = 2.0
BROADCAST_ADDR = "255.255.255.255"

class LanBeacon:
    def __init__(self):
        self._enabled = False
        self._port = BEACON_PORT
        self._base_id = ""
        self._base_name = ""
        self._server_port = 8000
        self._running = False
        self._task: asyncio.Task | None = None
        self._recv_task: asyncio.Task | None = None
        self._discovered_peers: dict[str, dict] = {}  # base_id -> info

    def configure(self, enabled: bool, port: int, base_id: str, base_name: str, server_port: int):
        self._enabled = enabled
        self._port = port
        self._base_id = base_id
        self._base_name = base_name
        self._server_port = server_port

    async def start(self):
        """Start broadcast + recv if enabled."""
        if not self._enabled:
            return
        self._running = True
        self._task = asyncio.create_task(self._broadcast_loop())
        self._recv_task = asyncio.create_task(self._recv_loop())

    async def stop(self):
        self._running = False
        if self._task: self._task.cancel()
        if self._recv_task: self._recv_task.cancel()

    async def _broadcast_loop(self):
        sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM, socket.SOCK_DGRAM)
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1)
        payload = json.dumps({
            "base_id": self._base_id,
            "base_name": self._base_name,
            "port": self._server_port,
            "ts": time.time(),
        })
        while self._running:
            sock.sendto(payload.encode(), (BROADCAST_ADDR, self._port))
            await asyncio.sleep(BEACON_INTERVAL)

    async def _recv_loop(self):
        sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM, socket.SOCK_DGRAM)
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        sock.bind(("", self._port))
        sock.settimeout(1.0)
        while self._running:
            try:
                data, addr = sock.recvfrom(4096)
                msg = json.loads(data.decode())
                bid = msg.get("base_id", "")
                if bid and bid != self._base_id:
                    self._on_peer_discovered(msg, addr)
            except asyncio.CancelledError:
                raise
            except Exception:
                pass

    def _on_peer_discovered(self, msg: dict, addr: tuple):
        """Register peer in network_bases (same as hub heartbeat)."""
        from services import network as net
        net.heartbeat(
            base_id=str(msg["base_id"]),
            base_name=str(msg.get("base_name", "")),
            ip=addr[0],
        )
        self._discovered_peers[msg["base_id"]] = {
            "base_name": msg.get("base_name", ""),
            "ip": addr[0],
            "port": msg.get("port", 0),
            "ts": msg.get("ts", 0),
        }

    @property
    def discovered_peers(self) -> dict:
        return dict(self._discovered_peers)

_beacon: LanBeacon | None = None

def get_beacon() -> LanBeacon | None:
    return _beacon

def start_beacon_if_enabled():
    global _beacon
    from services import network as net
    cfg = net.get_config()
    _beacon = LanBeacon()
    _beacon.configure(
        enabled=bool(cfg.get("lan_beacon_enabled", False)),
        port=int(cfg.get("lan_beacon_port", BEACON_PORT)),
        base_id=net.ensure_base_id(),
        base_name=str(cfg.get("base_name", "")),
        server_port=int(cfg.get("port", 8000)),
    )
    asyncio.create_task(_beacon.start())

async def stop_beacon():
    global _beacon
    if _beacon:
        await _beacon.stop()
```

## Risks

- **Firewall blocking UDP broadcast** — Windows Defender may block. Document in KNOWN_ISSUES.
- **Subnet-directed broadcast** — `255.255.255.255` may not reach across routers. Acceptable for LAN-only.
- **Port conflict** — beacon port configurable; default 8001 avoids conflict with API 8000.
